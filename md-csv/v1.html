How this tool works

    
  

  

    
1. Paste your table

    
Paste markdown into the left pane. The CSV appears on the right as you type. Outer pipes (|) are optional, so tables copied from chat answers work too.

    
A table is detected when its second line is a separator row like |---|---| or :--:. Text before, between or after tables is ignored.


    
2. Choose your options

    
    
      
  • Delimiter: comma, semicolon, tab or pipe. Use semicolon if your Excel expects it in a .csv.
    • 
      
  • Tables: “First only” converts the first table found. “All” converts every table, with a blank line between them.
    • 
      
  • Strip bold, code, links: turns **bold**, `code` and [text](url) into plain text. Untick it to keep the markdown as written.
    • 
      
  • Add BOM for Excel: adds a small marker to the downloaded file so Excel shows accents and symbols like ₹ correctly.
    • 
    


    
3. Check the result

    
Use the Text / Table switch above the output. Text shows the raw CSV. Table shows a grid, which makes a misaligned column easy to spot. The stats under each pane show rows, columns, size and any short rows that were padded with empty cells.


    
4. Get your data out

    
    
      
  • Copy for Excel: copies tab-separated data. Use it when pasting into Excel or Google Sheets, so each value lands in its own cell.
    • 
      
  • Copy CSV: copies real CSV text, for a .csv file or another program.
    • 
      
  • Download .csv: saves a file named table.csv.
    • 
    


    
5. Resize the panes

    
Drag the bar between the panes to change the left/right split, and drag the bar under them to make both panes taller. Double-click either bar to reset it. When a bar is focused, the arrow keys move it.


    
6. Good to know

    
    
      
  • Your text, options and pane sizes are saved in this browser only. Nothing is uploaded.
    • 
      
  • Clear asks you to click twice, so you don’t wipe your text by accident.
    • 
      
  • To keep a literal pipe inside a cell, write it as \|.
    • 
      
  • Rows with fewer cells than the header are padded with empty cells so every row has the same width.
    • 
      
  • Excel may turn values like 1-2 into dates or drop leading zeros when you paste. Format those columns as text first.
    • 
    


    
Quick fixes

    

      
Everything lands in one Excel columnUse Copy for Excel, not Copy CSV

      
Accents or ₹ look garbled in ExcelTick Add BOM for Excel, then download again

      
“No table yet”Check that the second line is a separator row (---)

      
Only one table convertedSet Tables to “All”
